# Operação e contratos

Python mantém SQLite em WAL, foreign keys e busy timeout de 30s. A versão do schema é 1; banco novo recebe criação transacional. Versões desconhecidas são rejeitadas. Ainda falta testar uma migração real entre versões de schema.

Projetos são cadastrados explicitamente por raiz absoluta. Leitura usa openat/O_NOFOLLOW em componentes relativos; rejeita traversal, arquivos especiais, symlinks, NUL binário, UTF-8 inválido e alterações durante a leitura. Padrão: 1 MB por arquivo. Exclusões incluem dependências, builds e nomes comuns de credenciais. Exclusões não são um detector universal de segredos: proteja documentos sensíveis pela política do projeto. Não cadastre o diretório pessoal inteiro.

`ce policy PROJETO` mostra política; `--set` recebe objeto JSON parcial com `exclude`, `external` e `max_file_bytes`. External é falso por padrão. Somente o conector Jev faz envio de código; recebe trechos limitados e redigidos. Credencial vem exclusivamente de TYPESAFE_API_KEY; não se lê auth.json do Codex. Ausência de chave, negação de política e falhas externas aparecem como fallback local. Requisições usam HTTPS fixo, timeout, uma tentativa e até 64 KB/32 perguntas. Ainda faltam limites globais de concorrência e calibração externa. Rankings são conselhos; não aprovam patches nem decidem encerramento.

FTS5/BM25 encontra palavras; coincidências literais têm prioridade. Modo estrutural consulta símbolos. Híbrido combina shortlist lexical com reranker local TF-IDF de caracteres (3–5), máximo de 500 documentos/30 mil atributos/32 mil caracteres por candidato. Modelo estatístico ajustado ao corpus, sem rede nem download de pesos; não equivale a embeddings neurais. Assisted chama Jev apenas para mais de três candidatos e quando permitido; falhas são identificadas. O modo full retorna arquivos de até 2001 linhas sob orçamento, com omissões explícitas. O orçamento mede bytes de itens de evidência serializados; não limita tokens globais ou o envelope JSON.

Grafo expande de 1 a 4 níveis e até 200 relações, filtrando direção/tipo. Relações de imports/chamadas sintáticas são inferidas, mesmo com um nome candidato único. TypeScript Compiler API 5.9.3 resolve aliases e referências; TypeScript 7 mudou o contrato e não é aceito por este adaptador. Libclang usa banco real de compilação e não executa o campo shell command. Diagnósticos e limites do compilador permanecem explícitos. Nenhuma análise demonstra todos os caminhos dinâmicos.

Indexação mantém snapshot de conteúdo não commitado, HEAD, raiz, política e versões. Transação única publica somente após segunda varredura idêntica. Interrupções revertem; outra indexação aguarda o lock SQLite. Cache de extração depende de caminho/hash/versão; relações são reconstruídas para invalidar dependências. Renomes sem alteração de conteúdo preservam file id quando o hash identifica um único arquivo removido. Símbolos usam file/kind/name/ocorrência e preservam identidade em deslocamentos de linhas. Renome com edição simultânea e overloads reordenados continuam limitados. O custo da verificação de freshness é uma varredura de conteúdo; benchmark de escala grande está pendente.

`ce status` retorna ready/partial/stale/missing. Partial traz arquivos omitidos/erros de parsing. Busca stale falha com instrução de indexar; a leitura direta retorna a fonte atual e permite precondição hash. O índice guarda cópia de fonte. Diretório de estado é privado (0700), banco 0600; backups/exports também devem ser protegidos. Não há criptografia em repouso.

Runner mantém stdout/stderr redigidos, exit code e duração no banco, resume começo/primeiro erro/final e permite expansão por linhas. Limite de armazenamento padrão 10 MB; ao atingir mata o grupo e informa output_limit. Timeout/cancelamento matam subprocessos do grupo. Redação reduz exposição comum, mas não garante detecção de todo segredo; redigidos não são logs byte a byte originais. Não há isolamento de CPU/memória de comandos arbitrários. `run` não usa shell; configurações npm/Gradle podem executar código do projeto e exigem raiz confiável.

MCP usa SDK oficial, stdio, sem porta de rede ou daemon permanente. Codex inicia/encerra o processo. Catálogo: evidence_search, evidence_read, evidence_graph, evidence_refresh, evidence_handoff, evidence_log. Tipos são gerados pelo SDK a partir das assinaturas. Evidências de cliente real estão em tests e evidence/codex-mcp-approved.jsonl. O esquema app-server foi gerado pela versão instalada em evidence/app-server-schema; execução usa exec oficial. Hooks não foram ativados. Não há masking do histórico, interceptação universal, teto global de tokens ou automação de OAuth.

Backup usa API SQLite e restore valida integridade/schema, fazendo backup prévio. Restore requer banco de destino legível e ausência de outras operações. Recuperação automática de banco corrompido ainda está pendente: preserve banco/WAL/SHM e restaure backup em uma instalação de estado separada com CE_HOME. Índice pode ser reconstruído com index --force enquanto banco estiver saudável. Não remova estado para corrigir um projeto sem backup.

Retenção por prune remove runs/eventos antigos e caches expirados; snapshots/extract caches não têm coleta completa ainda. Export contém logs e metadados, com arquivos de acesso privado. Logs de eventos podem conter dados do projeto. Não publique exports sem revisão.

Diagnóstico: ce doctor confirma binário, login (sem tokens OAuth), contratos disponíveis e integridade. Para MCP recusado por approval_policy=never, use o perfil economy; a primeira tentativa sem autorização configurada está preservada nas evidências. Timeout de compilador pode indicar projeto grande/configuração inadequada. Instale dependências opcionais explicitamente. Falhas de Codex preservam stderr/eventos; limite da assinatura não possui contador exposto por exec e não é estimado.

Validação reproduzível: `.venv/bin/pytest -q`; `.venv/bin/ruff check --config pyproject.toml src tests`; `.venv/bin/python -m build`; `.venv/bin/pip-audit`; `.venv/bin/python scripts/performance.py`. Os limiares de performance estão no docstring do script antes da execução; não representam SLA geral.
